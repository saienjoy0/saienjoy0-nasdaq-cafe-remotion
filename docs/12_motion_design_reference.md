# Motion Design Reference

更新日：2026-08-03

## 参照した実装

### remotion-dev/remotion

Remotion本体と公式例を、フレーム駆動アニメーションの正本として参照する。

### remotion-dev/github-unwrapped

データを一度に並べず、パネルの登場、数値のカウントアップ、視点移動、重要結果の拡大によって物語を進める実装を参照した。

採用した原理：

- `spring()`による要素の登場
- `interpolate()`による移動・拡大・線描画
- 大数字を主役にする構図
- 複数要素の時間差表示
- 完成状態を短く保持してから次へ進む

### reactvideoeditor/remotion-templates

比較チャート、段階表示、棒グラフ、進行ステップの構成を補助参考とした。

## 朝のNASDAQカフェへの適用

外部コンポーネントを実行時に読み込んだり、そのまま依存関係として組み込んだりしない。現在の`render_spec.json`契約へ合わせ、次のローカル部品として再実装する。

- 結論：大数字と中心仮説を分離して順次表示
- 数値比較：横棒とカウントアップ
- Expected / Actual / Gap：順番に開示
- 因果図：ノード表示後に矢印を描画
- 銘柄比較：中央ゼロの発散バー
- 検証点：チェック項目の順次表示
- 重要語：カードを増やさず、大きな文字とアクセント線で見せる

市場因果、数値、テロップ、順番は外部デザインから取得しない。すべて検証済み`render_spec.json`を正本とする。
