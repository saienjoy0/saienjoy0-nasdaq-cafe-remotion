# 金融ビジュアル 日本語UI契約

金融ビジュアルの固定UI文言は、日本の視聴者向けに日本語で表示する。

| Template | 固定表示 |
|---|---|
| `market-pulse-grid` | 市場スナップショット |
| `earnings-surprise` | 予想・実際・差分／予想／実際／差分 |
| `dual-asset-split` | 銘柄の明暗 |
| `macro-pressure` | マクロの波及 |
| `source-receipt` | 確認済みの根拠／確認済み資料／出典メモ |

## 金額表記

日本語番組の公開画面では、可能な場合は `B` や `billion USD` ではなく、意味を変えずに「億ドル」など日本語で読み取れる単位へ変換する。

例：

- `$42.3B` → `423億ドル`
- `$43.0B` → `430億ドル`
- `+$0.7B` → `+7億ドル`

## 境界

この契約は公開画面の言語と単位表記だけを扱う。ナレーション、市場因果、数値の意味、Template選択、Shot順、TTS入力、final権限は変更しない。

固定英語ラベルや旧語彙が再混入した場合は、金融テンプレートの回帰テストで停止する。
